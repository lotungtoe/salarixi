# Примечание

Данная документация опирается на последнюю версию Salarixi — 1.0.9

# Начало

## Для чего предназначен клиент

- **Стресс-тесты:** проверка серверов на мощность.
- **Автоматизация:** автоматическое выполнение задач.
- **Анализ данных:** анализирование сервера и игроков.
- **Тестирование:** проверка анти-бот и анти-чит систем.
- **Сбор данных:** сбор и сохранение данных из чата.
- **Проверка серверов:** поиск ошибок и уязвимостей.
- **Фарминг:** масштабные авто-фермы.

# Главная

## О разделе

Раздел _Главная_ — стартовая страница. Здесь задаётся подключение к серверу и запускаются или останавливаются боты.

## Поля

* `Адрес сервера` — IP или домен с портом, например: `mc.server.com`, `127.0.0.1:25565`. Если не указывать порт - будет установлен 25565 по умолчанию.
* `Версия Minecraft` — протокольная версия, например `1.20.1`. Важно понимать, что при использовании прокси доступна будет одна версия - `1.21.11`. Если вы используете версию не 1.21.1, при запуске на ваше устройство установится ViaVersion и запустится (если у вас есть установленная Java) на локальном сервере.
* `Кол-во ботов` — сколько всего ботов запускать.
* `Задержка подключений` — пауза в миллисекундах между подключениями. Снижает пиковую нагрузку на сервер. Рекомендуется ставить 4000-5000мс.

## Кнопки

* **Запустить** — старт ботов с текущими настройками. После запуска настройки невозможно изменить (можно менять значение, но на текущем процессе это не отобразится).
* **Остановить** — отключение всех ботов, очистка данных, выключение служб (график, мониторинг, радар).
* **Генерация** — случайная подстановка значений в поля (адрес, версия, кол-во, задержка).
* **Очистить** — сброс всех полей на странице.

# Настройки

## Основные

* `Никнейм` — легитный (из списка), случайный или кастомный. При кастомном появляется поле `Шаблон никнейма`: например `player_#m#m` (буквы и цифры).
* `Пароль` — легитный, случайный или кастомный. Для кастомного задаётся `Шаблон пароля`, например `#m#l#m#n`.

## Регистрация

* `Режим` — Обычный / Триггер. Обычный — боты будут регистрироваться через указанную задержку. Триггер — боты будут регестрироваться после появления указанного сообщения в чате.
* `Команда` — Команда регистрации, например `/register`.
* `Шаблон` — Шаблон регистрации, например `@cmd @pass`, `@cmd @pass @pass`. `@cmd` — команда, `@pass` — пароль.

## Логин

Аналогично настройкам регистрации.

## Прочее

* `Переподключение` — задержка в мс перед повторным подключением при отключении (если используется Auto-Rejoin).
* `Частота обновлений` — как часто обновлять данные мониторинга (мс).
* `Длина истории чата` — сколько последних сообщений хранить.
* `Дистанция прогрузки` — дальность прорисовки чанков.
* `Язык клиента` — язык клиента (доступен `en_us`).
* `Ведущая рука` — ведущая рука у ботов (`left` или `right`, ничего - случайный выбор).

## Скины

Данная функция будет работать только на серверах, которые поддерживают установку скина с помощью команды (например, сервера с плагином SkinRestorer).
Тип скина: по умолчанию, случайный или кастомный. Для кастомного указывается команда (например `skin`) и при необходимости ник игрока, с которого копировать скин.

## Опции (чекбоксы)

* **Использовать Auto-Register** — при включении боты будут автоматически регестрироваться.
* **Использовать Auto-Login** — при включении боты будут автоматически логиниться.
* **Использовать Auto-Rejoin** — при включении боты будут автоматически переподключаться к серверу, если их кикнуло.
* **Использовать Chat-Signing** — при включении боты будут автоматически выполнять операцию Chat-Signing.
* **Использовать Auto-Respawn** — при включении боты будут моментально респавнится при событии смерти.
* **Использовать Accept-RP** — при включении боты будут принимать и обрабатывать все пакеты с ресурс паками.
* **Использовать Pathfinder** — при включении боты смогут использовать функции pathfinder'а.
* **Использовать Auto-Script** — при включении и получении события о спавне для каждого бота отдельно будет запускаться написанный тобой ранее сценарий.
* **Использовать прокси** — при включении боты будут использовать указанные тобой прокси (настраивать в разделе _Прокси_).
* **Использовать анти-капчу** — при включении боты будут использовать анти-капчу (настраивать в разделе _Анти-Капча_).
* **Использовать вебхук** — при включении некоторые данные будут отправляться (настраивать в разделе _Вебхук_).
* **Использовать аккаунты** — при включении на панели управления появится раздел _Аккаунты_, при запуске будут использоваться аккаунты из списка.

# Плагины

## О разделе

Плагины — поведения ботов, которые отвечают за автоматическое выполнения определённых операций.
Выключать и включать плагины возможно только **до запуска**.

# Прокси

## Список прокси

Прокси вводятся в текстовое поле — по одному на строку. Для SOCKS5 формат: `ip:port`, `socks5://ip:port`, `ip:port@username:password`, `socks5://ip:port@username:password`.
Кнопка `Очистить список` удаляет все записи.

## Сборщик прокси

Сборщик прокси — специальный инструмент, который позволяет автоматически собирать прокси с публичных ресурсов. Важно понимать, что он не проверяет прокси на работоспособность.
У сборщика есть настройки (алгоритм, протокол, страна, количество, порт). Самой главной опцией у сборщика является алгоритм поиска — UPc и APIc.

- Алгоритм UPc (universal proxy collection) — данный алгоритм позволяет собирать большое количество прокси со множества ресурсов, но он может работать не быстро и не поддерживает фильтрацию по странам.
- Алгоритм APIc (API collection) — данный алгоритм ограничивает допустимые ресурсы для сборщика прокси, работает быстро, найденные прокси могут работать лучше чем у UPc.
Кнопка _Найти прокси_ запускает поиск. Статус поиска показывается под кнопкой.

# Анти-Капча

## Типы и подтипы капчи

- **Web** — боты будут ловить ссылку из чата по указанному вами регулярному выражению и обязательной части ссылки. После действия бота зависят от режима: **ручной** — боты отправят ссылку на капчу в раздел _Анти-Капча_, которую можно будет открыть, нажав на кнопку _решить капчу_; **авто** — ещё до получения первой капчи запустится указанный вами браузер. Как только бот получит ссылку на капчу, он устанновит прокси для браузера (если возможно) и откроет ссылку.
- **Map (Inventory)** — боты будут ожидать появления предмета FilledMap (заполненная карта) в инвентаре, после чего создавать изображение и отправлять в раздел _Анти-Капча_, решить её можно там же нажав на кнопку _решить капчу_ в разделе _Анти-Капча_.
- **Map (Frame)** — боты будут ожидать появления сущностей ItemFrame / GlowItemFrame и собирать из них единое изображение до того, как не закончится лимит (колонны * ряды).

## Настройки Web

- `Регулярное выражение` — для извлечения ссылки из чата. По умолчанию подставляется выражение для ссылок вида `https?://[^\s]+` (без пробелов).
- `Обязательная часть ссылки` — фильтр: обрабатываются только ссылки, содержащие эту подстроку (например `anti-bot`).
- `Адрес сервера для WebDriver` (если указан режим авто) — локальный адрес, на котором у вас должен быть заранее запущенный WebDriver (например http://localhost:4444 для geckodriver).

# Вебхук

## Настройка

Поле `Ссылка` — URL вебхука (например Discord).

## Чекбоксы

_Информация_ — отправка информационных сообщений. _Данные_ — отправка данных. _Действия_ — события действий ботов.
При включённом вебхуке в настройках клиент может отправлять уведомления (например о спавне бота) на указанный URL.

# Управление

## Группа

Поле `Группа` — имя группы ботов. Команды управления применяются к этой группе. Ниже — подразделы с модулями.

## Управление / Чат

Режим `Сообщение` — одно сообщение по кнопке «Отправить». Режим `Спамминг` — непрерывная отправка с задержками мин/макс.
Опции: Синхронность, Глобальный чат, Мутация текста, Магический текст. Для спамминга: Анти-Повтор, Обход.

## Управление / Действия

Действие: Джампинг, Шифтинг, Махание рукой. Старт/Стоп. Синхронность и Импульсивность (случайные задержки).

## Управление / Инвентарь

Режим `Базовый`: выбор слота, Выбрать/Выбросить, Клик ЛКМ/ПКМ. Режим `Перемещение`: слот, целевой слот, кнопка «Переместить».
`Индекс слота` — слот 0–8 или индекс в инвентаре.

## Управление / Движение

Режим: Обычный или Pathfinder. Направление: Вперёд, Назад, Влево, Вправо. Для Pathfinder задаются координаты X и Z. Синхронность, Импульсивность.

## Управление / Анти-АФК

Режим: Минимальный, Нормальный или Продвинутый. Задержки мин/макс в мс. Предотвращает кик за AFK за счёт периодических действий.

## Управление / Полёт

Режимы: Vanilla, Jump-Fly, Teleport-Fly, Bug-Fly. Настройки: Адаптивные или Ручные (задержки, изменение по Y, Ground-Spoof). Анти-чит: Vulcan, Grim, Intave или без.

## Управление / Киллаура

Поведение: Умеренное или Агрессивное. Настройки адаптивные или ручные: дистанция атаки, задержка. Цель: Игрок, Монстр, Животное. Оружие: Меч или Топор, при ручных настройках — слот.
Опции: Авто оружие, Доджинг, Преследование (дистанция и мин. дистанция до цели), Критические удары.

## Управление / Скаффолд

Режимы: Noob Bridge, Ninja Bridge, God Bridge, Jump Bridge. Задержка в мс, угол взгляда по X (мин и макс в градусах) для размещения блоков под ногами.

## Управление / Анти-Падение

Режимы: Hovering, Teleport, Water-Drop. Fall-Spoof отключён. Триггер по расстоянию до земли и по скорости падения, задержка срабатывания.

## Управление / Лук аим

Цель: Игрок, Монстр, Животное или Своя цель (вводится никнейм). Задержка и максимальная дистанция.

## Управление / Стиллер

Цель: Сундук, Бочка или Шалкер. Задаются радиус взаимодействия и задержка между действиями. Автоматический вынос предметов из контейнеров в радиусе.

## Управление / Майнер

Режим: Обычный или Расширенный. В расширенном — туннель (2x2x2 … 3x3x3) и поворот (Плавный/Резкий). Направление взгляда по Y, слот с инструментом, задержка в тиках.

## Управление / Фермер

Режимы: Нормальный, Быстрый, Ультра. Задержка между действиями. Модуль обрабатывает грядки: взлом земли, посадка, сбор; автоматически подбирает лучшую мотыгу из инвентаря.

# Скриптинг

## О разделе

Здесь вы можете писать свои сценарии для ботов на Rust, который будет выполняться в оболочке Rhai.
Важно: Оболочка Rhai не поддерживает некоторые концепции языка Rust, из-за чего их использование напрямую невозможно. Например: Нельзя использовать асинхронные операции, нельзя использовать _ в качестве названия переменной.

## Системные функции

- `sleep(delay: u64)` — остановка выполнения скрипта на время (в секундах).
- `print(str: &str)` — логгирование информации в терминал.
- `log(text: &str, class: &str)` — логгирование информации в журнал клиента.
- `message(name: &str, content: &str)` — отправка уведомления в клиент.
- `webhook(content: &str)` — отправка вебхука по ранее указанной ссылке.

## Простые функции

- `chat(mu: &str, message: &str)` — отправить сообщение в чат.
- `jump(mu: &str)` — одноразовый прыжок.
- `swing_arm(mu: &str)` — махнуть рукой.

## Основные функции-геттеры

- `active_bots_count() -> i64` — получить количество активных ботов.
- `get_bot_id(mu: &str) -> i64` — получить Entity ID определённого бота.
- `get_bot_ping(mu: &str) -> u32` — получить пинг определённого бота.
- `get_bot_feet_pos(mu: &str) -> (f64, f64, f64)` — получить позицию ног определённого бота.
- `get_bot_eye_pos(mu: &str) -> (f64, f64, f64)` — получить позицию глаз определённого бота.
- `get_bot_health(mu: &str) -> f64` — получить здоровье определённого бота.
- `get_bot_satiety(mu: &str) -> i64` — получить сытость определённого бота.
- `bot_is_workable(mu: &str) -> bool` — получить состояние работоспособности определённого бота.

## Основные функции-сеттеры

- `set_jumping(mu: &str, state: bool)` — задать состояние для jumping.
- `set_crouching(mu: &str, state: bool)` — задать состояние для crouching.
- `set_velocity(mu: &str, axis: &str, velocity: f64)` — задать скорость по определённой оси.
- `set_on_ground(mu: &str, on_ground: bool)` — задать состояние для on_ground.
- `set_old_position(mu: &str, x: f64, y: f64, z: f64)` — задать значение для old_position.
- `set_no_jump_delay(mu: &str, delay: i64)` — задать значение для no_jump_delay.
- `set_was_touching_water(mu: &str, state: bool)` — задать значение для was_touching_water.
- `set_has_impulse(mu: &str, state: bool)` — задать значение для has_impulse.

## Функции, отвечающие за различные действия

- `start_walking(mu: &str, direction: &str)` — идти по указанному направлению.
- `start_sprinting(mu: &str, direction: &str)` — бежать по указанному направлению.
- `start_pathfinder(mu: &str, x: i64, z: i64)` — идти на укзанные координаты.
- `stop_move(mu: &str)` — остановить движение (walk && sprint).
- `stop_pathfinder(mu: &str)` — остановить задачи pathfinder'а.
- `place_block(mu: &str, x: i64, y: i64, z: i64)` — установить блок на указанных координатах.
- `look_at(mu: &str, x: f64, y: f64, z: f64)` — повернуться на укзанные координаты.
- `look_at_block(mu: &str, x: f64, y: f64, z: f64)` — повернуться на блок с учётом его центра.
- `drop_selected_item(mu: &str, lock: bool)` — выбросить предмет, лежащий в руке.
- `inv_click(mu: &str, slot: i64, mode: i64, lock: bool)` — кликнуть определённым образом на указанный слот. Доступные режимы: 0 - Left click, 1 - Right click, 2 - Shift, 3 - Drop (Single), 4 - Drop (All).
- `inv_click_on(mu: &str, name: &str, mode: i64, lock: bool)` — кликнуть определённым образом на предмет с указанным именем.
- `set_selected_slot(mu: &str, slot: i64)` — установить выбранный слот в хотбаре.
- `attack(mu: &str, target: &str, distance: f64, look_at_target: bool)` — атака определённой ближайшей сущности. Аргумент `target` может иметь значения: any (любая сущность), player, monster, animal, vehicle.
- `start_use_item(mu: &str, hand: &str)` — начать использовать предмет в указанной руке (mainhand / offhand).
- `release_use_item(mu: &str)` — завершить использование предмета.

## Функции, отвечающие за состояния ботов

- `set_state(mu: &str, field: &str, value: bool)` — установить значение (true / false) для состояния определённого бота.
- `get_state(mu: &str, field: &str) -> bool` — получить значение состояния у опредлённого бота.

## Что за состояния ботов

Состояние бота — это значение для некого сектора действий (к примеру, атака, ходьба), влияющее на поведение и возможности бота.
Существует 2 вида состояний — `is` и `can`. Is-состояния отвечают за текущее положение бота (к примеру, бот сейчас ходит). Can-состояния отвечают за возможное положение бота (к примеру, сможет ли бот атаковать сущности).
Список всех доступных состояний:

- `can_walking`
- `can_sprinting`
- `can_eating`
- `can_drinking`
- `can_attacking`
- `can_looking`
- `can_interacting`
- `is_walking`
- `is_sprinting`
- `is_eating`
- `is_drinking`
- `is_attacking`
- `is_looking`
- `is_interacting`

## Пояснения

- Что означает аргумент `mu: &str` у многих функций? — Даннный аргумент определяет какой бот попадёт под ей влияние, то есть здесь указывается юзернейм бота. Если указать в этом поле `*`, то функция окажет влияние на всех существующих ботов.
- Что означает аргумент `lock: bool` у функций, который взаимодействуют с инвентарём? — Даннный аргумент определяет, можно ли блокировать состояния бота при взаимодействии или же нет.

# Радар

## О разделе

Радар позволяет отслеживать координаты указанных вами игроков, визуализировать маршрут, автоматически сохранять данные.
У радара есть ограничение — установленная дальность прорисовки **на сервере**, если цель (сущность) находится дальше максимальной дистанции прорисовки, боты не смогут получать актуальные данные о ней.

## Использование

Поле никнейма и кнопка добавления цели — отслеживание игроков по нику.
Кнопка удаления (на панели) — удаляет все существующие цели из списка.

## Настройки

Кнопка настроек открывает панель: `Частота обновления` (500–6000 мс). Полный путь и имя файла для указыватся для автоматического сохранения. Чекбокс _Авто сохранение_ позволяет включить автоматическое сохранение данных.

# Журнал

## О разделе

Журнал — лог событий клиента. Чекбоксы: _Системные логи_, _Расширенные логи_, _Авто скролл_. Кнопка очистки удаляет содержимое журнала.

# Интерфейс

## Глобальные настройки

- `Партиклы` — показать или скрыть партиклы на фоне.
- `Тема` — тема клиента, (цвета ключевых элементов).
- `Шрифт` — глобальный шрифт (кроме панели).
- `Сообщения` — показать или скрыть всплывающие уведомления.
- `Язык` — язык интерфейса (русский / английский).
- `Discord RPC` — включить или выключить отображение активности Discord.

## Настройки панели

- `Иконки` — показать или скрыть иконки у кнопок на панели.
- `Шрифт` — шрифт элементов на панели.
- `Размер шрифта` — размер шрифта элементов на панели.
- `Внутренний отступ` — внутренний отступ кнопки на панели между иконкой и текстом.

# Быстрые задачи

## Что это такое

Быстрые задачи (или же управление ботами с помощью горячих клавиш) — возможность управлять ботами при помощи **горячих клавиш**.
Управлять быстрыми задачами можно только во время **активного процесса**, то есть когда вы запустили ботов на сервер.

## Горячие клавиши

- `Shift + W` — идти вперёд (продолжительность 200мс).
- `Shift + A` — идти влево (продолжительность 200мс).
- `Shift + S` — идти назад (продолжительность 200мс).
- `Shift + D` — идти вправо (продолжительность 200мс).
- `Shift + I + C` — полностью очистить инвентарь.
- `Shift + J` — прыгнуть.
- `Shift + C` — присесть.
- `Shift + Alt + Q` — отключиться от сервера.
- `Shift + G + F` — полёт (изменение velocity по Y на 0.26±5).
- `Shift + G + R` — прыгнуть и поставить под себя блок.
- `Shift + G + C` — построить вокруг себя капсулу из блоков.
- `Shift + U` — объедениться (идти на центральные координаты по X и Z).
- `Shift + T` — повернуть голову на 50 градусов.
- `Shift + Z` — повернуть голову в исходное состояние (0.0, 0.0).
- `Shift + F + C` — сформировать круг (радиус зависит от кол-ва ботов).
- `Shift + F + L` — сформировать линию.
- `Shift + P + S` — остановить работу pathfinder.
