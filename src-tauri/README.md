# Backend

This is a section that contains main application logic - API, computational functions, modules, configs.

## Map

|       Relative Path         |                   Description                            |
|-----------------------------|----------------------------------------------------------|
| `./icons`                   | Application icons                                        |
| `./src/api`                 | API logic (backend <--> frontend)                        |
| `./src/bot`                 | All bot functionality                                    |
| `./src/launch`              | Process control logic, start and stop bots               |
| `./src/modules`             | Modules that are not directly related to the bot's logic |
| `./src/other`               | Other functionality (Discord RPC, webhook)               |
